游戏时光 隐私政策

项目反馈：GitHub Issues
政策版本：2026-10-21-main-v1

1. 适用范围与联系

本政策适用于游戏时光开源版本。更新和生效日期：2026年10月21日。使用问题与隐私相关咨询可通过项目 GitHub Issues 提交，请勿在公开反馈中包含个人敏感信息。

2. 启用查询与离线使用

同意本政策后才启用 Steam 查询和远程头像、封面、成就图片加载。不同意时可以阅读政策、使用离线演示与本地外观功能；演示图片以本地字母占位显示。你可随时在设置中重新选择。政策版本变化时会再次告知。

3. 你输入的信息

你自行输入 SteamID64 或个人主页、个人 Steam Web API 密钥，以及你选择的家庭共享选项，用于查询指定账号的个人游戏库、最近游玩记录和本人成就。本应用不要求、收集或保存 Steam 密码，不代你注册、注销 Steam 账号。请仅查询你本人或已获得合法授权的资料。

4. 查询取得的数据

接口返回的昵称、头像链接、SteamID、游戏名称和编号、累计/两周时长、最近游玩时间和更新日期用于展示与本地历史恢复。成就状态、描述和解锁时间用于当前查看，保存在本次使用的内存缓存。未取得的信息显示不可用；家庭共享清单仅在你主动登录本人Steam并启用后查询，时长和成就属于当前查询账号。

5. 网络接收方与境外服务

你的设备直接向 api.steampowered.com 发送 Steam 账号/游戏查询参数，并在 HTTPS 请求头发送 API 密钥。启用家庭共享后，还会向Steam接口发送家庭授权令牌和家庭组编号。封面素材查询仅发送游戏编号和语言，不携带个人密钥或家庭令牌。远程头像、游戏封面和成就图片由 Steam 及其 CDN 提供；请求会向对应服务商暴露网络 IP 和必要请求信息。Steam/Valve 的服务可能位于境外，其处理受 Steam 隐私政策约束。开发者不运营查询代理服务器、不向开发者上传上述数据，也不将数据用于广告。

6. 密钥与设备存储

选择记住密钥时，API密钥和家庭授权令牌分别保存在此应用的设备安全存储中，设备解锁后可读取，应用不启用密钥云同步；关闭记住并保存账号后移除持久密钥。游戏历史、昵称、头像链接、排序、账号与外观选择保存在设备应用沙箱。数据存储位置为你使用设备所在的国家或地区，本应用不设开发者云端数据存储。

7. 图片与系统能力

背景选图和图片取色使用系统选图器，只读取你明确选择的一张图片，不申请整库、通讯录、位置、麦克风等权限。背景会生成缩小后的本地副本；图片取色只在设备上处理，不上传原图。复制反馈地址或模板时仅写入你选择的文本，不读取剪贴板。打开 GitHub 反馈页由你主动操作，提交内容由你确认，并受 GitHub 隐私政策约束。

8. 保存期限与删除

本地游戏库缓存、账号和外观数据保留到你清除或卸载本应用；远程图片可能由系统缓存。同意/拒绝选择及政策版本在本地保存以避免重复询问。设置里的清除全部本地数据将删除本应用API密钥、家庭授权令牌和网页登录数据、游戏库缓存、排序、外观偏好、背景副本、缓存及隐私选择，恢复初始状态；相册原图和 Steam 上的资料不受影响。

9. 撤回同意与失败处理

你可在隐私页面撤回同意并清除全部本地数据。确认后应用会停止查询，作废旧请求结果并清理数据。如果删除未完成，会提示重试并保持联网关闭；下一次启动仍会尝试完成清理。撤回后可以选择离线使用。

10. 数据共享与安全

当前版本没有集成第三方广告、统计或开发者远程日志 SDK，不售卖个人信息。Steam API 密钥和家庭授权令牌不会写入普通偏好、反馈模板或日志。应用使用 HTTPS 和设备安全存储，但网络服务和设备环境仍可能影响可用性与安全。反馈时请勿发送 API 密钥、密码或含凭据的截图。

11. 未成年人

未成年人请在监护人指导下使用并了解本政策，不向客服发送身份证、密码或 API 密钥。有关隐私权利和误提交信息的处理，可由本人或监护人通过项目反馈渠道联系维护者，请勿公开未成年人的身份信息。

12. 家庭授权网页

家庭登录使用嵌入式Steam官方网页，账号密码由你直接输入Steam网页，本应用不读取密码输入框。登录Cookie、网页存储和资源缓存可能由系统Web组件保存在本应用中；你点击完成登录后，本应用读取Steam返回的授权令牌，用于家庭组和共享游戏清单查询。移除家庭授权或清除全部本地数据会清除相应本地授权和网页登录数据。该功能不代表已获得Valve对本工具的官方背书。

13. 政策更新与第三方声明

涉及处理目的、数据范围或接收方的重要变化会更新版本并重新告知。游戏时光是独立工具，与 Valve/Steam 无官方隶属或背书关系。Steam 数据按接口现状提供，准确性、完整性和持续可用性取决于服务及账号隐私设置。Steam隐私政策：https://store.steampowered.com/privacy_agreement/；Web API条款：https://steamcommunity.com/dev/apiterms。
